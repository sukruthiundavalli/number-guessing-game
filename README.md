# Number Guessing Game

A simple interactive number guessing game developed using C programming.

## Features
- Generates a random number between 1 and 100.
- Accepts guesses from the user.
- Provides high and low hints.
- Counts the number of attempts.
- Displays a congratulation message.

## Concepts Used
- Random number generation
- Do-while loop
- If-else statements
- User input
- Variables and operators

## Language
C Programming
